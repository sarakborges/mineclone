## Arquitetura / invariantes

`ARCHITECTURE.md` autoritativo: ownership único por fato, SystemParams por domínio, UI `src/ui`, `TargetedBlock` único, trabalho change-driven, filas deduplicadas `DeduplicatedQueue<T>`/`VoxelUpdateQueue` + `FrameWorkBudget`, sem scans globais/dirty writes redundantes. Streaming: seleção visible/preload → geração async → integração + seed direto da iluminação uma vez por residência (.38) → snapshot 3×3×3 → mesh async → render → archive/unload. Visible supera preload, tarefas não críticas podem ser preemptadas, outputs stale devem ser reencaminhados sem starvation. Malhas/filas terreno/fluidos/luz independentes; `ChunkRemeshTasks::lighting_revisions` é diferente de `VoxelWorld::chunk_mesh_revisions`; halo reconciliado após mesh inicial (.33); unload 26 vizinhos relevantes geometry+fluid (.40); relaxação de luz interativa publica cada lote (.41). Render HDR world order0 Skip, viewmodel order1 tonemap, UI SDR order2. Céu exato por bioma e relógio; fogColor artístico pendente. Sol/lua com órbitas/rise-set por dimensão, nuvens world-space. Hidrologia com endpoints XYZ partilhados, margem geral .12, fontes naturais de água autoritativas separadas do solver, sem água suspensa. Held block observa hotbar, R só placement.
